# Devinci Boeing 2707-300 for X-Plane 12

Downloads of the Devinci Boeing 2707-300 supersonic transport for X-Plane 12 (64-bit Windows).

## Install

1. Open the [latest release](https://github.com/Devinci297/B2707-300-Releases/releases/latest).
2. Download `Devinci_B2707_300_v<version>.zip`.
3. Back up any previous version, then extract the `Devinci_B2707_300` folder into `X-Plane 12/Aircraft`.

## Updates

From version 0.15.0 on, the aircraft checks this page for new releases. When one is available, the tablet shows it and **Dispatch > ABOUT & UPDATES** installs it, downloading only the parts that changed. Your settings and saved flights are kept.

The other files in each release are those update packages and their manifest. Extracting every package zip into `X-Plane 12/Aircraft` also gives a complete installation.
