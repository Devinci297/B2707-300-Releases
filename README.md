# Devinci Boeing 2707-300 for X-Plane 12

Downloads of the Devinci Boeing 2707-300 supersonic transport for X-Plane 12 (64-bit Windows).

## Install

1. Open the [latest release](https://github.com/Devinci297/B2707-300-Releases/releases/latest).
2. Download [the complete v0.16.3 aircraft](https://github.com/Devinci297/B2707-300-Releases/releases/download/v0.16.3/Devinci_B2707_300_v0.16.3.zip).
3. Back up any previous version, then extract the `Devinci_B2707_300` folder into `X-Plane 12/Aircraft`.

Pan Am, BOAC Speedbird 1965 and TWA Trans World 1968 are included in the complete aircraft.

## All-liveries download

[Download the v0.16.3 livery pack — 31 variants](https://github.com/Devinci297/B2707-300-Releases/releases/download/v0.16.3/B2707-300_v0.16.3_Livery_Pack.zip).

Updated 7 November 2026 with refreshed fuselage and wing surface finish and weathering, preserving the existing airline colours and markings. Install the complete aircraft first. Close X-Plane, back up personal livery edits, then extract the pack **into the aircraft folder** to merge its `liveries` folder, replacing matching files.

## Updates

From version 0.15.0 on, the aircraft checks this page for new releases. When one is available, the tablet shows it and **Dispatch > ABOUT & UPDATES** installs it. Your settings and saved flights are kept. Close X-Plane when the updater prompts, and wait for completion before reopening it.

The component ZIPs and `b2707_release_manifest.json` are used by the updater. For a manual installation, use the complete aircraft ZIP above; the all-liveries pack is optional and installed separately.
